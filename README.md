# 👽 GAMEO

A grid-based puzzle game where you guide an alien across an obstacle-filled grid using directional controls, reach the goal, and win!

🔗 **Play it here:** [https://vivekboyina.github.io/GAMEO/](https://vivekboyina.github.io/GAMEO/)

## 🎮 About the Game

GAMEO starts by asking the player to enter a grid size (n). It then generates an **n × n grid** scattered with obstacles. The player controls an alien character and must navigate it from the starting cell to the bottom-right corner of the grid (n, n) to win.

- Enter a custom grid size at the start of the game
- Obstacles are randomly placed across the grid
- Use the on-screen directional hand buttons (👆 👈 👉 👇) to move the alien
- Reaching the target cell (n, n) triggers a **"You Won!"** alert
- Pressing any button after winning shows an **"Already Won"** alert

## 🕹️ How to Play

1. Open the game and enter your desired grid size (n).
2. The grid will be generated with the alien placed at the starting position and obstacles scattered across the board.
3. Use the directional buttons to move the alien:
   - 👆 Up
   - 👈 Left
   - 👉 Right
   - 👇 Down
4. Avoid the obstacles while navigating toward the bottom-right corner of the grid.
5. Reach the final cell (n, n) to win the game!
